# The Router Confesses

A one-line excuse from a home Wi-Fi router for dropping the connection at the
exact moment a movie reaches its climax. The router turns the classic advice
back on itself: rebooting is the only therapy it gets, and the plot twist gave
it feelings it is not rated for.

## How to run

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (creating the directory if
missing). Python standard library only.
